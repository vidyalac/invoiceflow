Design notes & limitations

  • AI reads, rules decide. OCR and text extraction read the invoice. The decision comes from deterministic rules, so the same invoice in the same state always gets the same answer.
  • It never guesses. Missing or low-confidence fields become a hold with a drafted question, not a silent assumption.
  • 2-way match only. There is no goods-receipt data, so this is PO vs invoice, not a full 3-way match.
  • Stateful. Split POs are tracked by remaining balance, and every run feeds the duplicate check.
  • Fraud signals halt the run before any PO logic is applied.
